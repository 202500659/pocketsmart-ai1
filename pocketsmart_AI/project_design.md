# Phase 3 – Project Design

## System Architecture

User
↓
Frontend
↓
FastAPI Backend
↓
Gemini AI
↓
AI Generated Response
↓
Frontend

## Frontend
The frontend contains the HTML pages used to interact with the user.

## Backend
Python and FastAPI are used to handle requests and application logic.

## AI Layer
Google Gemini AI is used to process user requirements and generate
intelligent suggestions.
