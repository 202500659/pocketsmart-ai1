# Phase 1 – Brainstorming & Ideation

## Project Name
Pocket Smart AI

## Problem Identification
Users may need assistance in planning different activities such as
home planning, party planning, and jewellery planning.

## Proposed Solution
Pocket Smart AI is a Generative AI-based application that provides
smart suggestions based on user requirements.

## Main Idea
The application allows users to enter their requirements and receive
AI-generated suggestions.

## Main Features
- User Registration
- User Login
- Dashboard
- Home Planner
- Party Planner
- Jewellery Planner
- History
- Generative AI Integration

## Technologies
- HTML
- CSS
- JavaScript
- Python
- FastAPI
- Google Gemini AI
