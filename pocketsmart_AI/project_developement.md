## Backend Development

The backend was developed using Python and FastAPI.

### Main Backend File

main.py

The backend handles user requests, application routes and communication
between the frontend and AI services.

## AI Integration

The project uses Google Gemini AI to generate intelligent responses
based on user requirements.
