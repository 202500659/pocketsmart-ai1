# Phase 2 – Requirement Analysis

## Functional Requirements

1. Users should be able to register.
2. Users should be able to log in.
3. Users should be able to access the dashboard.
4. Users should be able to use the Home Planner.
5. Users should be able to use the Party Planner.
6. Users should be able to use the Jewellery Planner.
7. Users should be able to view previous activities.
8. The application should generate AI-based suggestions.

## Non-Functional Requirements

- User-friendly interface
- Fast response
- Secure handling of sensitive information
- Easy navigation
- Reliable AI responses

## Software Requirements

- Visual Studio Code
- Python
- FastAPI
- Google Gemini API
- Web Browser

## Hardware Requirements

- Computer/Laptop
- Internet Connection
